# Start Here — Stellar Portfolio v4 (Free Edition)

1. Extract the project ZIP. All source files are in the root; no nested project folder.
2. For a local preview, run `python -m http.server 8000` and open http://localhost:8000.
3. Run tests with `node --test *.test.mjs` (Node 20+).
4. On GitHub, use the files as the repository root. Connect to Vercel with framework **Other**, output `.`, and **no build command**.
5. No OpenAI API key, credits, environment variables or backend are required. The AI-generated quiz and its API endpoint are removed. The replacement quiz is a free, curated technology-question bank.
6. See `README.md` for architecture, editing content, quiz topics, game controls and troubleshooting.
